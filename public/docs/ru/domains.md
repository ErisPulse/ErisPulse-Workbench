# Домены

Бесплатный поддомен для опубликованного модуля: `plugin-<метка>.erisdev.com`. DNS управляется Workbench — вручную ничего настраивать не нужно.

## Лимиты

- До **2** доменов на модуль
- До **10** доменов на аккаунт

## Способы подключения

| Способ | Описание | Когда использовать |
|--------|----------|--------------------|
| **Ветка репозитория** (рекомендуется) | Содержимое ветки git-репозитория публикуется как сайт; поддерживаются GitHub, Codeberg и собственные инстансы Gitea/Forgejo/GitLab (доступность по HTTPS из интернета обязательна) | Документация и демо модуля живут в репозитории |
| **Перенаправление** | 301-редирект на указанный https-адрес | Контент размещён в другом месте, нужен запоминающийся адрес |
| **Свой сервер** (расширенный) | Платформа создаёт проксируемую DNS-запись (CNAME / A / AAAA) на ваш сервер; трафик идёт через Cloudflare | Собственные серверы и развёртывания |

## Как подать заявку

Страница «Домены» (или страница модуля → кнопка «Домены») → выберите модуль → введите метку → выберите способ → отправить.

- **Правила метки**: 2-63 символа — строчные буквы, цифры и внутренние дефисы; служебные имена (www, api, admin и т.п.) недоступны
- **Ветка репозитория**: если репозиторий совпадает с зарегистрированным у модуля, домен активируется сразу; иначе нужен файл подтверждения (см. ниже)
- **Перенаправление**: активно сразу после отправки

## Подтверждение владения

**Ветка репозитория (другой репозиторий)**: разместите файл `erisdev-site-verify.txt` в **корне ветки** с кодом проверки, показанным при заявке, затем нажмите «Проверить» в Workbench.

**Свой сервер**: сервер должен отдавать код проверки по адресу `https://<ваш-домен>/.well-known/erisdev-verify.txt` (сервер должен отвечать на запросы с Host этого домена), затем нажмите «Проверить».

Проверку можно повторять в любой момент; после успеха домен активируется сразу.

## Управление

- **Пауза / Возобновить / Удалить**: из списка доменов; аккаунтам с двухфакторной аутентификацией нужен код TOTP
- Удаление домена типа «свой сервер» также удаляет управляемую DNS-запись
- При смене репозитория или ветки требуется повторная проверка (кроме случая того же репозитория)

## Правила использования и злоупотребления

Домены привязаны к владению модулем, содержимое должно относиться к модулю. Фишинг, вредоносное ПО и другое злоупотребление администраторы отключают без предупреждения. О злоупотреблениях сообщайте через каналы связи, указанные в подвале workbench.erisdev.com.
