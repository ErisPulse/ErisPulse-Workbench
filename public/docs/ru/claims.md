# Права на модули

Владение определяет, кто может редактировать и удалять модуль.

## Автоматически

| Сценарий | Владение |
| --- | --- |
| Вход через GitHub / Codeberg OAuth | Сопоставление по uid отправителя (старые данные как `github:<id>`) |
| Отправка внутри Workbench | `wb:<ваш uid>` |

## Вручную

Если автоматическое сопоставление невозможно (например, отправки эпохи Yunhu):

1. Откройте карточку модуля
2. «Заявить права»
3. Укажите причину (ссылки на репозиторий/пакет помогают)
4. Дождитесь проверки администратором

После одобрения владение переходит к вам. Повторные заявки отклоняются; прогресс — в «Мои заявки».
