# Модули

## Отправка

«Новый модуль» → заполнить → отправить. Уходит через `repository_dispatch` в ErisPulse-ModuleRepo; модуль появляется после завершения workflow.

| Поле | Обязательно | Примечание |
| --- | --- | --- |
| `name` | ✓ | буквы / цифры / `_` / `-` |
| `type` | ✓ | `module` или `adapter` |
| `package` | ✓ | имя пакета PyPI |
| `description` | ✓ | ≥10 символов, языки через `|` |
| `author` | ✓ | автор |
| `repository` | ✓ | github.com / codeberg.org |
| `category` | ✓ | 1 Инструменты / 2 Развлечения / 3 Управление / 4 Уведомления / 5 AI / 6 Платформы / 7 Аналитика |
| `tags` | | массив |
| `i18n` | | языки интерфейса |
| `min_sdk_version` | | минимальная версия SDK |
| `logo` | | https или data:image, ≤100КБ |

## Правка

Карточка модуля → изменения → «Сохранить». Владелец правит все поля; `verified` — только администратор.

Логотип можно вставить картинкой; фронтенд сжимает до ≤100КБ.

## Пакетные операции

Кнопка «Выбрать» на странице списка:

- Отметьте модули и нажмите «Подтвердить / Снять подтверждение / Удалить» (до 50)
- Одна проверка 2FA, один dispatch
- «Отмена» выходит из режима выбора

## Статусы

| Метка | Значение |
| --- | --- |
| Подтверждение обработка | Отправлено, workflow выполняется |
| Подтверждение ожидает | Не применилось за 30 минут — повторите или проверьте workflow |
| Проверен / Не проверен | Фактическое состояние в индексе |

Список сверяется при каждом обновлении: операция завершается только когда снимок действительно отражает целевое состояние.

## Права

| Роль | Возможности |
| --- | --- |
| Владелец | Правка всех полей своих модулей, удаление, заявка на владение |
| admin / mod | Дополнительно: верификация любых модулей, рассмотрение заявок, пакетные операции |

## Задержка синхронизации

Обычно до 10 секунд, максимум несколько минут. Если статус «ожидает» долго — проверьте Actions в ErisPulse-ModuleRepo.
