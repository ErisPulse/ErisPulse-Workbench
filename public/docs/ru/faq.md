# Вопросы

| Вопрос | Ответ |
| --- | --- |
| Код не приходит | Проверьте спам; отправитель `erisdev@88.com`; повтор через 10 минут |
| При регистрации просит «сначала получить код» | Нажмите «Отправить код» на карточке регистрации |
| Кнопка OAuth серая | Провайдер не настроен; используйте код/пароль или попросите администратора |
| Забыли пароль | Войдите по коду → Настройки → задайте новый пароль |
| Коды 2FA не подходят | Синхронизируйте время устройства по сети |
| Потерян секрет 2FA | Самостоятельно не восстановить; администратор очищает `totp_secret` в D1 |
| Потерян токен | Не восстанавливается — отзовите и создайте новый |
| Список не меняется после отправки | См. статусы в разделе «Модули»; обычно до 10 секунд |
| «Только администраторы» при верификации | Верификация — действие администратора; пользователи правят только свои модули |
| Аватар не обновляется | URL кэшируется 10 минут; подождите или добавьте параметр |
