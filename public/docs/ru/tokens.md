# Токены и открытый API

Токены доступа (PAT) — для CLI, CI и внешних инструментов.

## Создание

Страница «Токены доступа» → имя → «Создать токен». Формат: `epat_` + 40 hex-символов, до 10 на пользователя.

> Показывается один раз.

**Токен без 2FA (рекомендуется для CLI/CI)**: аккаунты с включённой 2FA могут отметить «Токен без 2FA». При создании нужен один код; далее чувствительные эндпоинты (отправка / управление / пакетные) не требуют `totp_code`. В списке появится бейдж «без 2FA».

## Вызов

```http
Authorization: Bearer epat_…
Content-Type: application/json
```

Права токена совпадают с вашими правами в веб-интерфейсе.

## Эндпоинты

| Эндпоинт | Метод | Назначение |
| --- | --- | --- |
| `/api/modules` | GET | Индекс модулей (владельцы, верификация) |
| `/api/modules/submit` | POST | Отправка модуля / адаптера |
| `/api/modules/manage` | POST | Правка / верификация / удаление (одного) |
| `/api/modules/batch` | POST | Пакетно: верификация / снятие / удаление |
| `/api/me` | GET | Информация об аккаунте |
| `/api/userinfo` | GET | Информация о пользователе (с `avatar_url`) |
| `/api/modules/ops` | GET | Статус операций: `?name=&type=` — недавние операции по модулю (владелец/админ); без параметров — ваши недавние |
| `GET /api/health` | — | Проверка здоровья (публичный) |
| `GET /api/meta` | — | Самоописание API (публичный) |
| `GET /api/modules/stats` | — | Статистика экосистемы (публичный) |
| `GET /api/modules?q=запрос` | — | Нечёткий поиск (имя/пакет/описание/теги) |

## Пример

```bash
curl -X POST https://workbench.erisdev.com/api/modules/submit   -H "Authorization: Bearer epat_…"   -H "Content-Type: application/json"   -d '{
    "name": "MyModule",
    "type": "module",
    "package": "ErisPulse-MyModule",
    "description": "Описание, не менее 10 символов",
    "author": "Your Name",
    "repository": "https://github.com/you/MyModule",
    "category": 1,
    "tags": ["tool"],
    "i18n": ["zh", "en"],
    "min_sdk_version": ">=2.7.0"
  }'
```

Пакетно:

```json
{
  "action": "verify",
  "items": [{ "name": "MyModule", "type": "module" }],
  "totp_code": "123456"
}
```

При включённой 2FA эндпоинты отправки и управления требуют `totp_code`.

## 428 и льготный период

Если 2FA требуется, а код отсутствует/истёк — `428 TOTP_REQUIRED`; веб-интерфейс спросит код сам, API-клиенту нужно повторить с `totp_code`. После успешной проверки **веб-сессия имеет 10-минутный льготный период** (PAT не входят, кроме токенов «без 2FA»).
