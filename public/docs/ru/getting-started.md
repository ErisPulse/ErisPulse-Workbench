# Начало работы

Workbench — центр идентификации ErisPulse: один аккаунт для всех сервисов и управления правами на модули.

## Вход

Три независимых способа, один аккаунт:

| Способ | Процесс |
| --- | --- |
| Код | Имя или email → код → вход |
| Пароль | Имя или email + пароль |
| OAuth | GitHub / Codeberg / Yunhu в один клик |

Кнопки OAuth находятся под формой; серая — провайдер не настроен. OAuth-аккаунту можно добавить email в настройках, чтобы включить вход по коду/паролю.

## Регистрация

Требуется подтверждение email:

1. Введите имя, email, пароль
2. Нажмите «Отправить код» и введите 6-значный код
3. «Зарегистрироваться и войти»

Код действует 10 минут, отправитель — `erisdev@88.com`.

## Настройки аккаунта

Аватар справа вверху → Настройки:

- **Отображаемое имя**: видно во всех сервисах
- **Аватар**: сжимается при загрузке, общий для всех сервисов
- **Пароль**: установка / сброс
- **Email**: привязка / смена (новый адрес требует нового кода)
- **Связанные личности**: GitHub / Codeberg / Yunhu

## Двухфакторная аутентификация

Настройки → «2FA» → включить, отсканировать QR-код в приложении-аутентификаторе (или ввести секрет вручную) и подтвердить 6-значным кодом.

После включения:

- Вход по коду и паролю требует второй фактор
- Отправка / правка / удаление модулей требует код (диалог на странице; в API — `totp_code`)
- Вход через OAuth дополнительно не запрашивает код

Отключение: введите текущий код на той же карточке. **Потеря секрета означает потерю доступа**.
