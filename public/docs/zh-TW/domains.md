# 託管網域

為已發布的模組申請免費子網域：`<前綴>.plugin.erisdev.com`。工作台代管解析，無需自己操作 DNS。

## 限額

- 每個模組最多 **2** 個網域
- 每個帳戶最多 **10** 個網域

## 三種接入方式

| 方式 | 說明 | 適用場景 |
|------|------|----------|
| **儲存庫分支**（推薦） | 指定 git 儲存庫與分支，分支內容直接作為站點展示；支援 GitHub、Codeberg 及自建 Gitea·Forgejo、GitLab 公開實例（需公網可經 HTTPS 存取） | 模組文件、演示頁放在儲存庫裡 |
| **重新導向** | 存取時 301 轉址到你填寫的 https 位址 | 內容已託管在別處，只想要一個好記的入口 |
| **自有伺服器**（進階） | 平台代建 proxied 解析記錄（CNAME / A / AAAA）指向你的伺服器，流量經 Cloudflare 代理 | 自建伺服器、自行部署站點 |

## 申請流程

「託管網域」頁（或模組詳情頁 → 託管網域按鈕）→ 選擇模組 → 填寫前綴 → 選擇接入方式 → 提交。

- **前綴規則**：2-63 位小寫字母、數字或中綴連字號；官方保留名（www、api、admin 等）不可用
- **儲存庫分支模式**：如果儲存庫與該模組登記的儲存庫同源，申請後立即生效；否則需要放置驗證檔案（見下）
- **重新導向模式**：提交即生效

## 所有權驗證

**儲存庫分支模式（跨儲存庫）**：在儲存庫分支**根目錄**放置 `erisdev-site-verify.txt`，內容為申請時給出的驗證碼，然後在工作台點擊「驗證」。

**自有伺服器模式**：讓伺服器對 `https://<你的網域>/.well-known/erisdev-verify.txt` 回傳驗證碼內容（伺服器需支援 Host 為該網域的請求），然後在工作台點擊「驗證」。

驗證可隨時重試；通過後網域立即生效。

## 管理操作

- **暫停 / 恢復 / 刪除**：網域列表內操作，開啟兩步驗證的帳戶需輸入動態碼
- 刪除自有伺服器模式的網域會同時刪除代建的解析記錄
- 換儲存庫 / 換分支後需重新驗證（同源儲存庫除外）

## 使用限制與濫用處理

託管網域綁定模組所有權，內容應與模組相關。託管釣魚、惡意軟體等違規內容，或用於違法用途，管理員會直接停用且不另行通知。發現濫用請透過 workbench.erisdev.com 頁腳管道舉報。
