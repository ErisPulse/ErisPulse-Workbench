# 模組提交與管理

## 提交模組

「提交新模組」→ 填寫欄位 → 提交。提交後透過 `repository_dispatch` 下發到 ErisPulse-ModuleRepo，workflow 完成後入商店。

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| `name` | ✓ | 字母 / 數字 / `_` / `-` |
| `type` | ✓ | `module` 或 `adapter` |
| `package` | ✓ | PyPI 套件名 |
| `description` | ✓ | ≥10 字元，多語言用 `|` 分隔 |
| `author` | ✓ | 作者名 |
| `repository` | ✓ | github.com / codeberg.org |
| `category` | ✓ | 1 工具 / 2 娛樂 / 3 管理 / 4 通知 / 5 AI / 6 平台 / 7 分析 |
| `tags` | | 標籤陣列 |
| `i18n` | | 介面語言 |
| `min_sdk_version` | | 最低 SDK 版本 |
| `logo` | | https 或 data:image，≤100KB |

## 編輯

模組詳情頁 → 修改任意欄位 →「儲存修改」。所有者可改全部欄位；`verified` 僅管理員可改。

Logo 支援直接貼上圖片，前端自動壓縮到 ≤100KB。

## 批次操作

清單頁點「選取」進入選取模式：

- 勾選多個模組，可一鍵「批次轉正 / 批次取消驗證 / 批次刪除」（上限 50 項）
- 一次 2FA 校驗、一次 dispatch
- 點「取消」退出選取模式

## 狀態含義

| 標記 | 含義 |
| --- | --- |
| 轉正 處理中 | 已下發，workflow 執行中 |
| 轉正 待確認 | 超過 30 分鐘仍未生效，請稍後重試 |
| 已驗證 / 待驗證 | 倉庫索引中的真實狀態 |

清單重新整理時會自動對帳：只有快照確實反映目標狀態，操作才算完成。

## 權限

| 角色 | 可做 |
| --- | --- |
| 所有者 | 編輯自己模組的全部欄位、刪除、發起認領說明 |
| admin / mod | 額外驗證任意模組、審核認領、批次操作 |

## 同步延遲

通常提交後 10 秒內生效，最遲數分鐘。若長時間停在「待確認」，檢查 ErisPulse-ModuleRepo 的 Actions。
