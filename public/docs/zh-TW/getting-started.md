# 快速開始

小 Eris 工作台是 ErisPulse 的統一身分中心：一個帳戶登入所有生態服務，同時管理模組歸屬與認證資訊。

## 登入

三種獨立方式，進入同一個帳戶：

| 方式 | 流程 |
| --- | --- |
| 驗證碼 | 輸入使用者名稱或信箱 → 收驗證碼 → 登入 |
| 密碼 | 使用者名稱或信箱 + 密碼 |
| OAuth | GitHub / Codeberg / 雲湖 一鍵登入 |

OAuth 按鈕位於表單下方；灰色表示該渠道未設定。OAuth 帳戶可在「帳號設定」補綁信箱，之後即可用驗證碼 / 密碼登入。

## 註冊

必須完成信箱驗證：

1. 填寫使用者名稱、信箱、密碼
2. 點「發送驗證碼」，輸入收到的 6 位驗證碼
3. 「註冊並登入」

驗證碼 10 分鐘有效，寄件者 `erisdev@88.com`，收不到請檢查垃圾郵件。

## 帳號設定

右上角頭像 →「帳號設定」：

- **暱稱**：對外顯示名
- **頭像**：上傳自動壓縮；所有接入工作台身分的服務共用
- **密碼**：設定或重設，啟用密碼登入
- **信箱**：綁定 / 更換（新信箱需重新驗證）
- **身分綁定**：GitHub / Codeberg / 雲湖

## 兩步驗證（2FA）

「帳號設定」→「兩步驗證」→ 開啟，用認證器應用掃二維碼（或手動錄入密鑰），輸入 6 位動態碼確認。

開啟後：

- 驗證碼登入、密碼登入成功後，需再輸入一次動態碼
- 提交 / 編輯 / 刪除模組等敏感操作需要動態碼（頁面彈窗；API 呼叫附 `totp_code`）
- OAuth 登入不額外要求動態碼

關閉：在同一卡片輸入目前動態碼。**密鑰遺失將無法登入**，請備份。
