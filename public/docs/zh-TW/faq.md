# 常見問題

| 問題 | 處理 |
| --- | --- |
| 驗證碼收不到 | 檢查垃圾郵件；寄件者 `erisdev@88.com`；10 分鐘後可重發 |
| 註冊提示「請先取得信箱驗證碼」 | 先點註冊卡裡的「發送驗證碼」 |
| OAuth 按鈕是灰色 | 該渠道未設定，改用驗證碼 / 密碼，或聯絡管理員設定密鑰 |
| 忘記密碼 | 用驗證碼登入 → 帳號設定 → 重新設定密碼 |
| 2FA 動態碼總是不對 | 確認手機時間與網路自動同步 |
| 2FA 密鑰遺失 | 無法自行恢復，需管理員在 D1 清除該帳戶 `totp_secret` |
| 權杖遺失 | 無法找回，撤銷後重新產生 |
| 提交後清單沒變化 | 見「模組提交與管理」的狀態含義；通常 10 秒內生效 |
| 提示「僅管理員可驗證模組」 | 轉正是管理員操作，一般使用者只可編輯自己的模組 |
| 頭像不更新 | 頭像 URL 快取 10 分鐘，稍等或加隨機參數重新整理 |
