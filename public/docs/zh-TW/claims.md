# 歸屬認領

模組歸屬決定誰可以編輯與刪除。

## 自動認領

| 場景 | 歸屬 |
| --- | --- |
| 透過 GitHub / Codeberg OAuth 登入 | 依歷史提交者 uid 自動匹配（舊資料以 `github:<id>` 記錄） |
| 在工作台內提交 | 直接歸屬 `wb:<你的 uid>` |

## 手工認領

歷史資料無法自動匹配時（例如雲湖時期提交）：

1. 開啟模組詳情
2. 點「認領此模組」
3. 填寫理由（說明你是開發者，可附倉庫 / 套件連結）
4. 等待管理員審核

審核通過後歸屬轉移到你的帳戶，之後即可編輯與刪除。重複提交會被拒絕，進度可在「我的認領申請」查看。
