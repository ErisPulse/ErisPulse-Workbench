# 模块提交与管理

## 提交模块

「提交新模块」→ 填写字段 → 提交。提交后通过 `repository_dispatch` 下发到 ErisPulse-ModuleRepo，workflow 完成后入商店。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | ✓ | 字母 / 数字 / `_` / `-` |
| `type` | ✓ | `module` 或 `adapter` |
| `package` | ✓ | PyPI 包名 |
| `description` | ✓ | ≥10 字符，多语言用 `|` 分隔 |
| `author` | ✓ | 作者名 |
| `repository` | ✓ | github.com / codeberg.org |
| `category` | ✓ | 1 工具 / 2 娱乐 / 3 管理 / 4 通知 / 5 AI / 6 平台 / 7 分析 |
| `tags` | | 标签数组 |
| `i18n` | | 界面语言 |
| `min_sdk_version` | | 最低 SDK 版本 |
| `logo` | | https 或 data:image，≤100KB |

## 编辑

模块详情页 → 修改任意字段 →「保存修改」。所有者可改全部字段；`verified` 字段仅管理员可改。

Logo 支持直接粘贴图片，前端自动压缩到 ≤100KB。

## 批量操作

列表页点「选择」进入选择模式：

- 勾选多个模块，可一键「批量转正 / 批量取消验证 / 批量删除」（上限 50 项）
- 一次 2FA 校验、一次 dispatch，比逐条操作快得多
- 点「取消」退出选择模式

## 状态含义

| 标记 | 含义 |
| --- | --- |
| 转正 处理中 | 已下发，workflow 执行中 |
| 转正 待确认 | 超过 30 分钟仍未生效，请稍后重试或检查 workflow |
| 已验证 / 待验证 | 仓库索引中的真实状态 |

列表刷新时会自动对账：只有快照确实反映目标状态，操作才算完成。

## 权限

| 角色 | 可做 |
| --- | --- |
| 所有者 | 编辑自己模块的全部字段、删除、发起认领说明 |
| admin / mod | 额外验证任意模块、审核认领、批量操作 |

## 同步延迟

通常提交后 10 秒内生效，最迟数分钟。若长时间停在「待确认」，检查 ErisPulse-ModuleRepo 的 Actions 是否失败。
