# 归属认领

模块归属决定谁可以编辑与删除。

## 自动认领

| 场景 | 归属 |
| --- | --- |
| 通过 GitHub / Codeberg OAuth 登录 | 按历史提交者 uid 自动匹配（旧数据以 `github:<id>` 记录） |
| 在工作台内提交 | 直接归属 `wb:<你的 uid>` |

## 手工认领

历史数据无法自动匹配时（例如云湖时期提交）：

1. 打开模块详情
2. 点「认领此模块」
3. 填写理由（说明你是开发者，可附仓库 / 包链接）
4. 等待管理员审核

审核通过后归属转移到你的账户，之后即可编辑与删除。重复提交会被拒绝，进度可在列表的「我的认领申请」查看。
