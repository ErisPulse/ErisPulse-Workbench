# 托管域名

为已发布的模块申请免费子域名：`<前缀>.plugin.erisdev.com`。工作台代管解析，无需自己操作 DNS。

## 限额

- 每个模块最多 **2** 个域名
- 每个账户最多 **10** 个域名

## 三种接入方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **仓库分支**（推荐） | 指定 git 仓库与分支，分支内容直接作为站点展示；支持 GitHub、Codeberg 及自建 Gitea·Forgejo、GitLab 公开实例（需公网可经 HTTPS 访问） | 模块文档、演示页放在仓库里 |
| **重定向** | 访问时 301 跳转到你填写的 https 地址 | 内容已托管在别处，只想要一个好记的入口 |
| **自有服务器**（高级） | 平台代建 proxied 解析记录（CNAME / A / AAAA）指向你的服务器，流量经 Cloudflare 代理 | 自建服务器、自部署站点 |

## 申请流程

「托管域名」页（或模块详情页 → 托管域名按钮）→ 选择模块 → 填写前缀 → 选择接入方式 → 提交。

- **前缀规则**：2-63 位小写字母、数字或中缀连字符；官方保留名（www、api、admin 等）不可用
- **仓库分支模式**：如果仓库与该模块登记的仓库同源，申请后立即生效；否则需要放置验证文件（见下）
- **重定向模式**：提交即生效

## 所有权验证

**仓库分支模式（跨仓库）**：在仓库分支**根目录**放置 `erisdev-site-verify.txt`，内容为申请时给出的验证码，然后在工作台点击「验证」。

**自有服务器模式**：让服务器对 `https://<你的域名>/.well-known/erisdev-verify.txt` 返回验证码内容（服务器需支持 Host 为该域名的请求），然后在工作台点击「验证」。

验证可随时重试；通过后域名立即生效。

## 管理操作

- **暂停 / 恢复 / 删除**：域名列表内操作，开启两步验证的账户需输入动态码
- 删除自有服务器模式的域名会同时删除代建的解析记录
- 换仓库 / 换分支后需重新验证（同源仓库除外）

## 使用限制与滥用处理

托管域名绑定模块所有权，内容应与模块相关。托管钓鱼、恶意软件等违规内容，或用于违法用途，管理员会直接停用且不另行通知。发现滥用请通过 workbench.erisdev.com 页脚渠道举报。
