# 快速开始

小 Eris 工作台是 ErisPulse 的统一身份中心：一个账户登录所有生态服务，同时管理模块归属与认证信息。

## 登录

三种独立方式，进入同一个账户：

| 方式 | 流程 |
| --- | --- |
| 验证码 | 输入用户名或邮箱 → 收验证码 → 登录 |
| 密码 | 用户名或邮箱 + 密码 |
| OAuth | GitHub / Codeberg / 云湖 一键登录 |

OAuth 按钮位于表单下方；灰色表示该渠道未配置。OAuth 账户可在「账号设置」补绑邮箱，之后即可用验证码 / 密码登录。

## 注册

必须完成邮箱验证：

1. 填写用户名、邮箱、密码
2. 点「发送验证码」，输入收到的 6 位验证码
3. 「注册并登录」

验证码 10 分钟有效，发件人 `erisdev@88.com`，收不到请检查垃圾邮件。

## 账户设置

右上角头像 →「账号设置」：

- **昵称**：对外显示名
- **头像**：上传自动压缩；所有接入工作台身份的服务共享该头像
- **密码**：设置或重置，启用密码登录
- **邮箱**：绑定 / 更换（新邮箱需重新验证码验证）
- **身份绑定**：GitHub / Codeberg / 云湖

## 两步验证（2FA）

「账号设置」→「两步验证」→ 开启，用认证器应用扫二维码（或手动录入密钥），输入 6 位动态码确认。

开启后：

- 验证码登录、密码登录成功后，需要再输入一次动态码
- 提交 / 编辑 / 删除模块等敏感操作需要动态码（页面弹窗；API 调用附 `totp_code`）
- OAuth 登录不额外要求动态码

关闭：在同一卡片输入当前动态码。**密钥丢失将无法登录**，请备份。
