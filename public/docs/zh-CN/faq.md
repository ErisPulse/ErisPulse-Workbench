# 常见问题

| 问题 | 处理 |
| --- | --- |
| 验证码收不到 | 检查垃圾邮件；发件人 `erisdev@88.com`；10 分钟后可重发 |
| 注册提示「请先获取邮箱验证码」 | 先点注册卡里的「发送验证码」 |
| OAuth 按钮是灰色 | 该渠道未配置，改用验证码 / 密码，或联系管理员配置密钥 |
| 忘记密码 | 用验证码登录 → 账号设置 → 重新设置密码 |
| 2FA 动态码总是不对 | 确认手机时间与网络自动同步；认证器时区无关但时间必须准确 |
| 2FA 密钥丢失 | 无法自行恢复，需管理员在 D1 清除该账户 `totp_secret` |
| 令牌丢失 | 无法找回，撤销后重新生成 |
| 提交后列表没变化 | 见「模块提交与管理」的状态含义；通常 10 秒内生效 |
| 提示「仅管理员可验证模块」 | 转正是管理员操作，普通用户只可编辑自己的模块 |
| 头像不更新 | 头像 URL 缓存 10 分钟，稍等或加随机参数刷新 |
| 公司网络打不开 OAuth | 回调地址是固定域名，需要能访问 `workbench.erisdev.com` |
