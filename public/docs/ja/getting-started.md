# はじめに

Workbench は ErisPulse の統一 ID センターです。1 つのアカウントで全サービスにログインでき、モジュールの所有権も管理します。

## ログイン

3 つの独立した方式、同じアカウント：

| 方式 | 流れ |
| --- | --- |
| コード | ユーザー名またはメール → コード受信 → ログイン |
| パスワード | ユーザー名またはメール + パスワード |
| OAuth | GitHub / Codeberg / Yunhu ワンクリック |

OAuth ボタンはフォームの下にあります。グレーは未設定を意味します。OAuth アカウントは「アカウント設定」でメールを追加するとコード / パスワードでもログインできます。

## 新規登録

メール認証が必須です：

1. ユーザー名・メール・パスワードを入力
2. 「コード送信」を押し、届いた 6 桁コードを入力
3. 「登録してログイン」

コードは 10 分間有効、送信元は `erisdev@88.com`。

## アカウント設定

右上のアバター →「アカウント設定」：

- **表示名**：全サービスで表示
- **アバター**：アップロード時に自動圧縮、Workbench の ID を使う全サービスで共有
- **パスワード**：設定・再設定でパスワードログインを有効化
- **メール**：追加・変更（新しいアドレスは再認証が必要）
- **連携 ID**：GitHub / Codeberg / Yunhu

## 2 要素認証（2FA）

「アカウント設定」→「2FA」→ 有効化し、QR コードを認証アプリでスキャン（またはシークレットを手動入力）、6 桁コードで確定します。

有効化後：

- コード / パスワードログインには追加でコードが必要
- モジュールの登録・編集・削除などの重要操作にコードが必要（ページ内ダイアログ、API は `totp_code`）
- OAuth ログインは追加要求なし

無効化：同じカードで現在のコードを入力。**シークレットを失うとログインできません**。
