# FAQ

| 質問 | 対応 |
| --- | --- |
| コードが届かない | 迷惑メールを確認。送信元 `erisdev@88.com`。10 分後に再送可 |
| 登録で「先にコードを取得」と出る | 登録カードの「コード送信」を押す |
| OAuth ボタンがグレー | 未設定のプロバイダー。コード / パスワードを使うか管理者に依頼 |
| パスワードを忘れた | コードでログイン → アカウント設定 → 再設定 |
| 2FA コードが合わない | 端末の時刻をネットワーク同期に |
| 2FA シークレットを紛失 | 自力復旧不可。管理者が D1 で `totp_secret` を削除 |
| トークン紛失 | 復元不可。失効して再発行 |
| 登録後に一覧が変わらない | 「モジュール」の状態表示を参照。通常 10 秒以内 |
| 「管理者のみ承認可」と出る | 承認は管理者操作。一般ユーザーは自分のモジュールのみ編集可 |
| アバターが更新されない | URL は 10 分キャッシュ。少し待つかキャッシュ回避パラメータを付与 |
