# 所有権の申請

所有権は編集・削除の権限を決めます。

## 自動

| ケース | 所有権 |
| --- | --- |
| GitHub / Codeberg OAuth でログイン | 過去の投稿者 uid で照合（旧データは `github:<id>`） |
| Workbench 内で登録 | `wb:<あなたの uid>` |

## 手動

自動照合できない場合（Yunhu 時代の投稿など）：

1. モジュール詳細を開く
2. 「このモジュールを請求」
3. 理由を記入（リポジトリ / パッケージのリンクがあると確実）
4. 管理者の審査を待つ

承認後に所有権が移転し、編集・削除が可能になります。重複申請は拒否されます。
