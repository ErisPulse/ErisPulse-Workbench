# ホストドメイン

公開済みモジュールに無料のサブドメインを申請できます：`plugin-<プレフィックス>.erisdev.com`。DNS はワークベンチが管理するため、手動の DNS 操作は不要です。

## 上限

- モジュールごとに最大 **2** 件
- アカウントごとに最大 **10** 件

## 接続方式

| 方式 | 説明 | 用途 |
|------|------|------|
| **静的サイト更新**（zip ≤5MB） | zip（解凍後 ≤20MB）をアップロードするとプラットフォームの R2 で直接ホスト。行内の「再アップロード」で更新可能 | サーバーや Pages 設定なしで静的ページを公開 |
| **リポジトリ分支**（推奨） | git リポジトリのブランチ内容をそのままサイトとして表示。GitHub・Codeberg に加え、自前 Gitea/Forgejo/GitLab インスタンスにも対応（HTTPS で公開到達可能であること） | モジュールのドキュメントやデモをリポジトリで管理している |
| **リダイレクト** | アクセス時に入力した https アドレスへ 301 転送 | 内容は別の場所でホスト済みで、覚えやすい入口が欲しい |
| **自前サーバー**（上級） | プラットフォームが proxied DNS レコード（CNAME / A / AAAA）を作成し、トラフィックは Cloudflare 経由 | 自前サーバーでの運用 |

## 申請手順

「ホストドメイン」ページ（またはモジュール詳細ページ → ホストドメインボタン）→ モジュールを選択 → プレフィックスを入力 → 接続方式を選択 → 送信。

- **プレフィックス規則**：2〜63 文字の小文字英字・数字・内部ハイフン。公式の予約名（www、api、admin など）は利用不可
- **リポジトリ分支方式**：モジュール登録のリポジトリと同じ場合は即時有効。それ以外は検証ファイルが必要（下記）
- **リダイレクト方式**：送信した時点で有効

## 所有権の検証

**リポジトリ分支方式（別リポジトリ）**：ブランチの**ルート**に検証コードを内容とする `erisdev-site-verify.txt` を配置し、ワークベンチで「検証」をクリック。

**自前サーバー方式**：`https://<ドメイン>/.well-known/erisdev-verify.txt` が検証コードを返すようにサーバーを設定し（Host がこのドメインのリクエストに応答必須）、「検証」をクリック。

検証はいつでも再試行できます。通過するとドメインは即時有効になります。

## 管理

- **一時停止 / 再開 / 削除**：ドメイン一覧から操作。二段階認証を有効化しているアカウントは TOTP コードが必要
- 自前サーバー方式のドメインを削除すると、管理 DNS レコードも削除されます
- リポジトリやブランチを変更した場合は再検証が必要（同一リポジトリの場合を除く）

## 利用ポリシーと悪用への対応

ホストドメインはモジュールの所有権に紐づき、内容はモジュールに関連するものにしてください。フィッシングやマルウェアなどの悪用は管理者により通知なく停止されます。悪用を見つけた場合は workbench.erisdev.com のフッターからご報告ください。
