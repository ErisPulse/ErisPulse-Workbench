# モジュール

## 登録

「新規モジュール」→ 入力 → 送信。`repository_dispatch` で ErisPulse-ModuleRepo に送られ、workflow 完了後にストアへ反映されます。

| フィールド | 必須 | 説明 |
| --- | --- | --- |
| `name` | ✓ | 英数字 / `_` / `-` |
| `type` | ✓ | `module` / `adapter` |
| `package` | ✓ | PyPI パッケージ名 |
| `description` | ✓ | 10 文字以上、多言語は `|` 区切り |
| `author` | ✓ | 作者名 |
| `repository` | ✓ | github.com / codeberg.org |
| `category` | ✓ | 1 ツール / 2 エンタメ / 3 管理 / 4 通知 / 5 AI / 6 プラットフォーム / 7 分析 |
| `tags` | | 配列 |
| `i18n` | | UI 言語 |
| `min_sdk_version` | | 最小 SDK バージョン |
| `logo` | | https または data:image、100KB 以下 |

## 編集

詳細ページ → 変更 →「変更を保存」。所有者は全フィールドを編集可、`verified` は管理者のみ。

ロゴは画像を貼り付けでき、フロントエンドが 100KB 以下に自動圧縮します。

## 一括操作

一覧の「選択」を押すと選択モードになります：

- 複数選択して「一括承認 / 一括承認取消 / 一括削除」（最大 50 件）
- 2FA 検証 1 回・dispatch 1 回
- 「キャンセル」で選択モードを終了

## 状態表示

| 表示 | 意味 |
| --- | --- |
| 承認 処理中 | 送信済み、workflow 実行中 |
| 承認 確認待ち | 30 分経過しても未反映。再試行または workflow を確認 |
| 認証済み / 未認証 | リポジトリ上の実際の状態 |

一覧の再読み込み時に自動照合され、スナップショットが目標状態を反映したときだけ完了になります。

## 権限

| ロール | 可能な操作 |
| --- | --- |
| 所有者 | 自分のモジュールの全フィールド編集・削除・所有権申請 |
| admin / mod | 任意モジュールの承認、申請審査、一括操作 |

## 反映遅延

通常 10 秒以内、遅くとも数分。「確認待ち」が続く場合は Actions を確認してください。
